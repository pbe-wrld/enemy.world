# PUBLIC ENEMY — GitHub Pages

A three-page-style single-page website for PUBLIC ENEMY.

## Pages

1. WHO — landing page
2. PROFILES — FOUNDER / THREATS / ENEMY profile tabs
3. ABOUT — group description + Discord invite

## Files

- `index.html` — website structure
- `style.css` — complete design
- `script.js` — profiles, navigation, modal, images
- `assets/` — place your local images here

## IMPORTANT: first page images

The first-page background and two logos were originally supplied through ChatGPT/Gemini links. Those links are not stable GitHub assets.

Put the actual files in `/assets` and keep these names:

- `page1-background.jpg`
- `page1-left-logo.png`
- `page1-right-logo.png`
- `top-logo.png`

Then the website will automatically use them.

## Recommended profile images

The profile image URLs currently point to the Discord CDN. For a permanent GitHub Pages website, download each profile image and put them in `/assets/profiles/`, then replace the URLs in `script.js` with local paths.

## GitHub Pages

Upload all files to your repository root.

Then:

`Settings → Pages → Deploy from a branch → main → / (root) → Save`

Your site will then be available through your GitHub Pages URL.
